# MobileHub — Mobile Shopping Catalog

A mobile shopping catalog web application built with **ASP.NET Web Forms, C#, and SQL Server**.

## About the Project

MobileHub is a web application for browsing mobile phones, exploring product details, and managing a shopping experience.

## Features

- Browse mobile phone products
- Search and filter products by price
- Sort product listings
- View product details and specifications
- Add products to a shopping cart
- Maintain a wishlist
- Checkout and place orders
- View order history

## Technologies Used

- Frontend:ASP.NET Web Forms, HTML, CSS
- Backend: C#
- Database: Microsoft SQL Server
- IDE: Microsoft Visual Studio

## Project Structure

- MobileShoppingCatalog.sln  — Visual Studio solution
- MobileShoppingCatalog/ — Application source code, web pages, configuration, and assets

## How to Run

1. Download or clone this repository.
2. Open MobileShoppingCatalog.sln in Microsoft Visual Studio.
3. Configure the required SQL Server database and connection string.
4. Ensure the database tables and required data are available.
5. Build and run the application in Visual Studio.
